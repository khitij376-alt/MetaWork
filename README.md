# MetaWork — 24/7 Voice-Only Autonomous Mobile Agent

[![License: MIT](https://img.shields.io/badge/License-MIT-emerald.svg)](LICENSE)
[![Platform: Android 8.0+](https://img.shields.io/badge/Platform-Android%208.0%2B-38BDF8.svg)](https://developer.android.com)
[![Voice Engine: Gemini Live API](https://img.shields.io/badge/Voice-Gemini%20Multimodal%20Live-F59E0B.svg)](https://ai.google.dev/gemini-api/docs/live-api)

**MetaWork** (`com.metawork.agent`) is a public open-source, 24/7 hands-free autonomous voice agent for Android hosted at [github.com/khitij376-alt/MetaWork](https://github.com/khitij376-alt/MetaWork). It operates with **no keyboard** and **no text prompt UI**—listening continuously in the background and executing multi-step tasks across your phone such as booking train, flight, bus, movie, or cab tickets, sending WhatsApp and SMS messages, and placing phone calls.
