# Contributing to MetaWork

Thank you for contributing to **MetaWork** ([khitij376-alt/MetaWork](https://github.com/khitij376-alt/MetaWork)), the open-source 24/7 voice-only autonomous mobile agent!

1. Fork `https://github.com/khitij376-alt/MetaWork` and create your branch from `main`.
2. Never commit API keys (`local.properties` is git-ignored).
3. All user interactions must remain 100% voice-driven with zero keyboard dependency.
4. Always require explicit verbal confirmation from the user before triggering final payment buttons.
